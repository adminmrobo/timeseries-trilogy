2-1对话

对话笔记 — “结构看起来相似，但思考方式不同，对吧？”

原对话原文生活：用计算器算 vs 一页一页读故事

🙋 提问者
RNN（LSTM）的窗口看起来和时间序列模型结构相似，但思考方式不同，对吧？
💬 回答者

对。输入形状完全相同。

ARIMA (p=7)      : [t-7, t-6, t-5, t-4, t-3, t-2, t-1] → t
LSTM (window=7)  : [t-7, t-6, t-5, t-4, t-3, t-2, t-1] → t

差别在于如何处理这7个数。

🧮 ARIMA — 计算器型选手

코치: "7일 데이터 줄게."
선수: "1일 전 × 0.5 + 2일 전 × 0.3 + … + 7일 전 × 0.02 = 내일 값!"

把7个值按固定比例混合。无论遇到什么情况，那个比例都不会改变。

📖 LSTM — 阅读型选手

코치: "7일 데이터 줄게."
선수: (하나씩 순서대로 읽으며)
      "7일 전… 기억해 두자."
      "6일 전… 별거 아니네, 흘려보내자."
      "4일 전… 급락이다, 중요해!"
      …
      "1일 전까지 읽고 나니, 이런 흐름이구나 → 예측"

按时间顺序阅读，并用 forget·input·output gate 随时决定记住什么、忘记什么。即使是同一个模型，输入不同，记住的内容也会不同。

📝 附注：对话中的“0.5, 0.3, …, 0.02”是说明用的示例比例。实际系数由数据估计，在下面实验的账本中，由于星期模式，7天前的系数反而会很大。

3实验

用两种方式运行同样的7格

模型：AR(7) · LSTM（隐藏4）生活：计算器 vs 一页一页读

换成日常来说

计算器型是把买菜的7张收据一起摊开，“按固定比例”相加。阅读型是一页一页翻阅故事书，在备忘录上写写擦擦。合上最后一页时，备忘录上剩下的东西就是判断的依据。

在模型里

ARIMA 以对7个值乘上固定系数后的加权和结束。LSTM 每读一个值，就修改一次隐藏状态 h 与细胞状态 c，并用读完第7格后的 h 进行预测。

输入窗口

动手看看 — 同一窗口，两位选手的验证14天

两个模型都只用训练200天学习，这里的评分以验证数据（8/21~）进行。

解析 — 一次性 vs 一格一格

  1. ARIMA：7个值 × 系数全部相加，再加上常数就结束。没有阅读顺序的概念（只是每个位置的系数已经固定）。
  2. LSTM：从7天前的值开始读。每读一次，门就决定“要擦除多少、写入多少、输出多少”，c 与 h 随之改变。
  3. 把滑块从0移到7，可以看到 h·c 的柱子在每一格都不同。改变输入窗口，即使是同一格，柱子也会不同。
  4. 最终的 h 乘以输出权重，就是 LSTM 的预测。

本节的局限 · “理解”一词只是比喻。h 与 c 只是数字，很难让人直接读出每一格代表什么。

用公式看 — 两种计算
ARIMA: ŷ = c + Σj=1..7 φj·yt−j
LSTM: h0=c0=0,   for s = 1…7: (hs, cs) = Cell(xs, hs−1, cs−1);   ŷ = w·h7 + b

Cell 内的门的算式在2-2展开。本页的 LSTM 会用训练区间的平均与标准差对输入进行标准化后读取，并把预测值换回万韩元单位。

4总结

什么是固定的，什么是随时变化的

模型：固定 φ vs 随输入变化的门生活：比例表 vs 备忘录

ARIMALSTM
训练后固定的东西系数 φ，常数 c权重 W，偏置 b
每次输入时重新计算的东西预测值一个门 i·f·o、候选 g、状态 h·c、预测值
改变顺序的话乘上的系数不同，答案就变了读的故事改变，记忆就改变
可解释性直接读出系数h·c 很难直接读懂

解析 — “权重固定，门每次不同”

  1. LSTM 训练结束后，权重 W 也是固定的。不同之处在于：用这个 W 在每个时点重新计算门的值。
  2. 因此，即使是同一位置（例如4天前）的值，依据前面读过什么，所反映的程度也会不同。
  3. 在 ARIMA 中，4天前值的比重永远只有 φ₄ 一个。

本节的局限 · LSTM 灵活，意味着“能表示更多情况”，而不是“总是预测得更准”（将在3-3再看）。

换成生成式 AI 来说

LLM 训练结束后权重也是固定的，但提示（输入）不同时，内部计算的注意力与状态会改变，从而给出不同的回答。“权重固定 ≠ 行为固定”这一点很相似。

比喻的局限 · 现代 LLM 不是 LSTM，而是 Transformer（注意力），它不是一格一格地看窗口内容，而是一次性全部看。
