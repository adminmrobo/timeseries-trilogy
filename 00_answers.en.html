1-1 Lookback and Window

  1. why · concept Why do we first match the lookback when comparing ARIMA and LSTM fairly?

    2. So LSTM learns faster

  2. big · interpretation In the big-picture table, what do the two models share?
    1. Processing
    2. Weights
    3. Input
    4. Interpretability

    Answer C — Both take a few past values as input. They split in how they process them.

  3. big · concept Why seal the 50 test days?

    2. To get a fair score after all choices are made
    3. For use when training data is short
    4. Because the data is only for LSTM

    Answer B — If you pick the lookback or order by looking at the test set, that score is no longer a score on “unseen data.”

    1. It predicts 14 days ahead
    2. It looks at the previous 14 days' values to predict the next day
    3. It trains 14 times

1-4 All at Once vs Rolling Forward

  1. lv1 · concept In multi-step forecasting, which 8/25 value enters the window for the 9/20 forecast?
    1. The actual 8/25 value
    2. The predicted 8/25 value
    3. The actual 8/18 value
    4. None enters

    Answer B — Forecasting all at once without knowing actuals after 8/20, so later days fill the window with predictions.

  2. lv1 · interpretation On the φ=0.5 ledger, the two methods had similar MAE. What is the most fitting explanation?

    2. Noise dies out quickly, so even when distant forecasts return to the weekday average, the loss is small
    3. The rolling calculation is wrong
    4. The test data got mixed in

    Answer B — Multi-step forecasts of a stationary AR converge to the long-run mean. If noise remains briefly, that mean is a fairly good forecast.

  3. lv1 · interpretation Why look at MAE separately for each 10-day block?
    1. To reduce computation
    2. Because a single overall average hides whether errors grow for distant days (accumulation)
    3. To save test data
    4. To speed up rolling

    Answer B — Accumulated error piles up on distant days. A single average dilutes it.

  4. lv1 · concept What condition is needed for rolling evaluation to match operation?
    1. Actual values arrive on time every day
    2. Lookback is 30 or more
    3. There is no test set
    4. Differencing is performed

    Answer A — Rolling imitates operations: receive today's actual value, then predict tomorrow.

    Answer B — The validation data has finished its job of choosing and is the newest information, so it's better to include it in the coefficients.

2-2 Opening the LSTM Gates

  1. g1 · concept If the forget gate f is close to 1, what happens?
    1. Almost all past memory is erased
    2. Almost all past memory is kept as is
    3. All new content is discarded
    4. Output is blocked

    Answer B — In c ← f⊙c + i⊙g, when f=1 the previous c remains intact.

  2. g1 · concept Why do gate values lie between 0 and 1?
    1. Because tanh is used
    2. Because σ (sigmoid) is used
    3. Because the data was normalized
    4. Because there are 6 hidden cells

    Answer B — σ squashes any value into 0 to 1, so it becomes a ratio of “how far to open.”

  3. g1 · interpretation In the notepad analogy, what corresponds to the hidden state h?
    1. The notepad itself
    2. The eraser
    3. What was just said aloud
    4. The pen

    Answer C — h = o⊙tanh(c): the part of the memo (c) sent outward at the output gate's rate.

  4. g2 · calculation With f=0.8, previous c=0.5, i=0.5, g=0.4, what is the new c?
    1. 0.20
    2. 0.40
    3. 0.60
    4. 0.90

    Answer C — 0.8×0.5 + 0.5×0.4 = 0.4 + 0.2 = 0.6.

  5. g2 · interpretation When the window is changed to a “surge week,” why does the gate color in the same cell change?
    1. Because the weights were retrained
    2. Because gates are recomputed at each step from the input and the previous h
    3. Because the picture is random
    4. Because the window length changed

    Answer B — Weights are fixed; gate values are recomputed each time from the input.

  6. g2 · concept How was the LSTM on this page trained?
    1. Clustering without answers
    2. Backpropagation unrolled through time, with Adam
    3. A person entered the gate values directly
    4. Tuned on test data

    Answer B — Gradients were computed by backpropagation through time (BPTT), sending errors backward along the time axis.

  7. g3 · concept Which gate was not in the original 1997 LSTM?
    1. Input gate
    2. Output gate
    3. Forget gate
    4. All three were present

    Answer C — The forget gate was added by Gers et al. (2000).

  8. g3 · interpretation What problem arises from endless input without a forget gate?
    1. There is no way to clear memory
    2. Learning is too fast
    3. Output is always 0
    4. The window length cannot be set

    Answer A — c ← c + i⊙g only adds, so used-up memories keep piling up.

    2. A nonlinear relationship where the size of one input changes the effect of another
    3. Data leakage

    Answer B — One ingredient changes the amount of another — a nonlinear combination of intertwined inputs.

  3. c2 · calculation How many weights and biases does an MLP with H=8 hidden neurons (2 inputs, 1 output) have?
    1. 17
    2. 24
    3. 33
    4. 64

    Answer C — Input weights 2×8=16, hidden biases 8, output weights 8, output bias 1 → 33 (= 4H+1).

    2. Because there is too much data
    3. Because test data was used
    4. Because there are no hidden neurons

  5. c2 · concept What data did the two models use for scoring in this experiment?
    1. 400 training samples
    2. 198 validation samples
    3. All of training + validation
    4. Test data

  6. c3 · concept What is the correct meaning of “all combinations” being theoretical?

  7. c3 · interpretation If training MAE keeps falling but validation MAE starts rising, what should you do?

    2. Suspect overfitting
    3. Check it with test data
    4. Can't be switched to AR

  8. c3 · concept What does the universal approximation theorem NOT tell us?
