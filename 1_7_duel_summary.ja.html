たとえの限界

  • 帳簿のたとえは1日1つの値しか扱えません。実際のデータには、欠損・複数の周期・複数のセンサーが混ざっています。
  • 「選手の記憶」はたとえにすぎず、AR は何かを記憶しているわけではありません。固定の係数で窓の値を混ぜているだけです。
  • このチャプターの勝敗は、ひとつの帳簿・ひとつのシードの結果です。一般法則として扱ってはいけません。

生成AIでいえば

LLM のファインチューニングでも、文脈長を増やすと1つの例に含まれる情報は増えますが、同じ計算予算で見られる例の数は減ります。「より多く見る 対 より多く練習する」のトレードオフは同じです。

たとえの限界 · 実際の LLM は係数が数十個ではなく数十億個あり、学習方式（勾配降下・自己教師あり）も AR の最小二乗法とは異なります。

Python で再現する — 帳簿 A と AR(7・14・30)、statsmodels の ARIMA

ページと同じ乱数（mulberry32）で同じ帳簿を作るので、numpy の部分はページの数字（3.60・3.16・2.74）と同じになります。statsmodels の部分は厳密尤度推定なので少し異なります。必要なもの：numpy、statsmodels。

import math
import numpy as np

def rng(a):
    """페이지의 rng(seed)와 같은 mulberry32 난수 — 같은 시드면 같은 장부"""
    a &= 0xFFFFFFFF
    def imul(x, y): return (x * y) & 0xFFFFFFFF
    def nxt():
        nonlocal a
        a = (a + 0x6D2B79F5) & 0xFFFFFFFF
        t = imul(a ^ (a >> 15), 1 | a)
        t = ((t + imul(t ^ (t >> 7), 61 | t)) & 0xFFFFFFFF) ^ t
        return ((t ^ (t >> 14)) & 0xFFFFFFFF) / 4294967296
    return nxt

def gauss(r):
    u = 0.0
    while not u:
        u = r()
    return math.sqrt(-2 * math.log(u)) * math.cos(2 * math.pi * r())

def make_series(seed=2026, n=300, phi=0.5, sd=3.0, level=100.0, weekly=(0, 4, 6, 5, 3, -7, -11)):
    """장부 A: 수준 100 + 요일 패턴 + AR(1) 잡음"""
    r, y, e = rng(seed), [], 0.0
    for t in range(n):
        e = phi * e + sd * gauss(r)
        y.append(level + weekly[t % 7] + e)
    return np.array(y)

def fit_ar(y, p, start=0, end=200, lam=1e-6):
    """AR(p) = ARIMA(p,0,0) 조건부 최소제곱 (페이지의 fitAR과 같은 식)"""
    X = np.array([[1.0] + [y[t - j] for j in range(1, p + 1)] for t in range(start + p, end)])
    Y = y[start + p:end]
    A = X.T @ X
    A[1:, 1:] += lam * len(Y) * np.eye(p)
    return np.linalg.solve(A, X.T @ Y)

def rolling_ar(beta, y, start, end):
    """매일 실제값을 받아 다음 날 하나를 예측"""
    p = len(beta) - 1
    return np.array([beta[0] + sum(beta[j] * y[t - j] for j in range(1, p + 1)) for t in range(start, end)])

def mae(a, b):
    return float(np.mean(np.abs(np.asarray(a) - np.asarray(b))))

y = make_series()                       # 2/2 ~ 11/28, 300일
for p in (7, 14, 30):                   # 1-5 · 1-7의 세 선수
    b = fit_ar(y, p, 0, 200)            # 훈련 200일
    print(f"AR({p}) 학습 샘플 {200 - p}개, 검증 MAE {mae(rolling_ar(b, y, 200, 250), y[200:250]):.2f}")
# → AR(7) 3.60 · AR(14) 3.16 · AR(30) 2.74 (페이지와 같다)

# 실무에서는 statsmodels로: 정확 가능도로 추정하므로 계수·숫자가 조금 다르다
from statsmodels.tsa.arima.model import ARIMA
res = ARIMA(y[:200], order=(14, 0, 0)).fit()      # ARIMA(p, d, q) — 여기서는 d=0, q=0
res = res.append(y[200:250], refit=False)          # 계수는 그대로 두고 검증 50일을 이어 붙임
pred = res.get_prediction(start=200, end=249)      # 1일 앞(롤링) 예측
print(f"statsmodels AR(14) 검증 MAE {mae(pred.predicted_mean, y[200:250]):.2f}")
print(pred.conf_int(alpha=0.05)[:3])               # 95% 예측구간 (1-4의 색 띠)
