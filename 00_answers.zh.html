1-1 lookback 与 window

  1. why · 概念 比较 ARIMA 与 LSTM 时，为什么要先统一 lookback？
    1. 为了让两个模型看到相同的过去
    2. 为了让 LSTM 学得更快
    3. 为了确定 ARIMA 的差分次数
    4. 为了增加测试数据

    答案 A — 输入条件相同，差异才能说来自“模型的思考方式”。

  2. big · 解读 在大图表中，两个模型“相同”的格子是？
    1. 处理
    2. 权重
    3. 输入
    4. 可解释性

    答案 C — 两者都以过去若干个值作为输入。差异从处理方式开始。

  3. big · 概念 为什么要把 50 天测试数据封存起来？
    1. 为了加快计算
    2. 所有选择结束后，才能得到公平的成绩单
    3. 训练数据不足时使用
    4. 因为只有 LSTM 使用这份数据

    答案 B — 选择 lookback 或阶数时若看了测试数据，这个成绩就不再是“第一次见到的数据”的成绩了。

  4. lv1 · 概念 lookback 为 14 是什么意思？
    1. 预测 14 天之后
    2. 看前 14 天的值来预测下一天
    3. 学习 14 次
    4. 每 14 天更换一次模型

    答案 B — 窗口长度 = 回看的天数。

  5. lv1 · 计算 用 lookback 14 预测 8/21 时，输入范围是？
    1. 8/6~8/19
    2. 8/7~8/20
    3. 8/8~8/21
    4. 8/1~8/14

    答案 B — 从 8/20 往前数 14 天：8/20、8/19、…、8/7。

  6. lv1 · 计算 AR(14) 模型（无差分、无 MA）包括常数在内要估计多少个数？
    1. 14
    2. 15
    3. 28
    4. 196

    答案 B — φ₁…φ₁₄ 共 14 个 + 常数 c 1 个 = 15 个。

  7. lv2 · 解读 把输入窗口换成“大涨的一周”后，会发生什么变化？
    1. 系数 φ
    2. 预测值
    3. lookback
    4. 系数的个数

    答案 B — AR 的系数在训练结束后固定。输入改变时，只有相乘的结果（预测）会改变。

  8. lv2 · 概念 “ARIMA 对所有 lag 一视同仁”这句话对吗？
    1. 对
    2. 错 — 按系数大小使用不同权重，但这些权重与输入无关、是固定的
    3. 错 — 只使用最近一个值
    4. 错 — 每次都重新学习权重

    答案 B — 与对话笔记的补充一致。区别不在于“是否一视同仁”，而在于“是否固定”。

  9. lv2 · 概念 同样的 lookback 下，LSTM 与 ARIMA 有何不同？
    1. 输入窗口更长
    2. 门会根据输入改变信息的流动
    3. 只有一个系数
    4. 无需正确答案即可学习

    答案 B — LSTM 的门值会在每个时间点根据输入与记忆重新计算。

1-2 训练、验证、测试的划分

  1. lv1 · 概念 如果把时间序列随机打乱后划分训练与验证，会产生什么问题？

    答案 B — 紧邻的日子是最强的提示，因此会在运营中看不到的信息上接受评分。

  2. lv1 · 解读 在打乱的划分中，前后插值模型的 MAE 比 AR(14) 低。正确的解释是？

    4. 验证数据有误

    答案 B — 如果得分高的原因是“未来信息”，那这个分数不是成绩，而是泄漏的大小。

    2. 所有选择结束后，只打开一次

    4. 验证数据不足时

  5. lv1 · 解读 φ₇ 很大，能否说“7 天前的销量是今天销量的原因”？

    3. 能，只要 φ₇ 超过 0.5

  6. lv2 · 概念 在 ARIMA(p, d, q) 中，与 lookback 直接对应的字母是？
    1. p
    2. d

  7. lv2 · 概念 对有趋势的账本做一阶差分会怎样？

    3. lookback 增加

  8. lv2 · 概念 MA(q) 项使用的是什么？
    1. 过去的值
    2. 过去的预测误差

    答案 B — MA 反映的是“昨天偏离了多少”。

1-4 一次预测 vs 滚动预测

  1. lv1 · 概念 在多步预测中，预测 9/20 时窗口里包含的 8/25 值是？
    1. 8/25 的实际值
    2. 8/25 的预测值
    3. 8/18 的实际值
    4. 不包含

    答案 B — 8/20 之后的实际值未知，因此一次性预测时，之后的日子要用预测值填充窗口。

  2. lv1 · 解读 在 φ=0.5 的账本上，两种方式的 MAE 相近。最恰当的解释是？
    1. 多步预测本来就更好
    2. 噪声很快消失，即使远期预测回到星期平均，损失也很小
    3. 滚动计算出错了
    4. 测试数据混入了

    答案 B — 平稳 AR 的多步预测会收敛到长期平均。若剩余噪声较短，该平均就是相当不错的预测。

  3. lv1 · 解读 为什么要按 10 天一组分别查看 MAE？
    1. 为了减少计算
    2. 因为只看整体平均，无法看出远期误差是否变大（累积）
    3. 为了节省测试数据
    4. 为了加快滚动计算

    答案 B — 累积误差集中在远期。单一平均会将其稀释。

  4. lv1 · 概念 要让滚动评估与运营一致，需要什么条件？
    1. 实际值每天按时到达
    2. lookback 至少为 30
    3. 没有测试数据
    4. 做差分

    答案 A — 滚动模拟的是“今天拿到实际值，再预测明天”的运营方式。

  5. lv2 · 计算 按步骤操作，预测 50 天测试的模型是用多少天训练的？
    1. 200 天
    2. 250 天
    3. 300 天
    4. 50 天

    答案 B — 选定后，用训练 200 + 验证 50 = 250 天重新训练。

  6. lv2 · 概念 看了测试 MAE 后再改变 lookback，会怎样？
    1. 测试分数变得更准确
    2. 测试变成了“用于选择的数据”，不再是公平的成绩
    3. 没有任何问题
    4. 验证数据会增加

    答案 B — 测试只能打开一次，才能得到第一次见到的数据的成绩。

  7. lv2 · 计算 第③步中用 250 天重新训练 AR(30)，（窗口，答案）配对有多少个？
    1. 170
    2. 220

  8. lv2 · 解读 用验证选定后再用 250 天重新训练，最合理的理由是？

    2. 为了把最近的 50 天也纳入系数估计
