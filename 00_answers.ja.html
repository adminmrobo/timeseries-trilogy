チャプター1 · 何日さかのぼるか

1-1 lookback と window

  1. why · 概念 ARIMA と LSTM を公平に比べるとき、まず lookback をそろえるのはなぜですか？
    1. 二つのモデルに同じ過去を見せるため
    2. LSTM がより速く学習するように
    3. ARIMA の差分の回数を決めるため
    4. テストデータを増やすため

    正解 A — 入力条件をそろえてこそ、違いが「モデルの考え方」から来ると言えます。

  2. big · 解釈 大きな図の表で、二つのモデルが「同じ」欄は？
    1. 処理
    2. 重み
    3. 入力
    4. 解釈可能性

    正解 C — どちらも過去の数個の値を入力として受け取ります。処理から分かれます。

  3. big · 概念 テストデータ50日を封印しておく理由は？
    1. 計算を速くするため
    2. すべての選択が終わった後に、公正な成績をもらうため
    3. 訓練データが足りないときに使うため
    4. LSTM だけが使うデータだから

    正解 B — lookback や次数を選ぶときにテストデータを見ると、その成績はもう「初めて見るデータ」の成績ではありません。

  4. lv1 · 概念 lookback が 14 だというのは？
    1. 14日後を予測する
    2. 直前 14 日の値を見て翌日を当てる
    3. 14回学習する
    4. 14日ごとにモデルを変える

    正解 B — 窓の長さ = さかのぼって見る日数です。

  5. lv1 · 計算 lookback 14 で 8/21 を予測するとき、入力の範囲は？
    1. 8/6~8/19
    2. 8/7~8/20
    3. 8/8~8/21
    4. 8/1~8/14

    正解 B — 8/20 から逆に 14 日: 8/20, 8/19, …, 8/7。

  6. lv1 · 計算 AR(14) モデル（差分・MA なし）が推定する数は、定数を含めて何個？
    1. 14
    2. 15
    3. 28
    4. 196

    正解 B — φ₁…φ₁₄ の 14 個 + 定数 c の 1 個 = 15 個。

  7. lv2 · 解釈 入力の窓を「急騰した週」に変えたとき、変わるのは？
    1. 係数 φ
    2. 予測値
    3. lookback
    4. 係数の個数

    正解 B — AR の係数は学習が終われば固定です。入力が変わると、掛け算の結果（予測）だけが変わります。

  8. lv2 · 概念 「ARIMA はすべての lag を等しく使う」という言葉は？
    1. 正しい
    2. 誤り — 係数の大きさぶん違う重みで使うが、その比重は入力に関係なく固定である
    3. 誤り — 一番直近の値だけを使う
    4. 誤り — 毎回比重を学習し直す

    正解 B — 対話ノートの補足そのままです。違いは「等しいか」ではなく「固定か」です。

  9. lv2 · 概念 同じ lookback でも、LSTM が ARIMA と違う点は？
    1. 入力の窓がより長い
    2. ゲートが入力に応じて情報の流れを変える
    3. 係数が一つしかない
    4. 正解なしで学習する

    正解 B — LSTM のゲートの値は、各時点で入力と記憶から計算し直されます。

  7. lv2 · 概念 傾向のある帳簿に 1 次差分をとると？
